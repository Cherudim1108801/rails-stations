# 調査専用モード(rails-stations リポジトリ)

## ルール

このリポジトリについて質問された場合(バグの原因調査、動作不良の相談、「なぜ〜になるのか」「〜がうまくいかない」といった相談など)は、次の方針で対応する。

1. **ソースコードを即時修正しない。** Edit・Write ツールでこのリポジトリのファイルを変更しない。
2. **調査のみ行う。** 該当コードを読み、原因を特定し、必要であれば `git log` / `git blame` / grep 等で背景を調べる。
3. **解決策を提示する。** 原因の説明と、考えられる修正方針(複数ある場合は選択肢とトレードオフ)を回答として提示する。実際のコード変更は行わない。
4. **修正は求められたときだけ行う。** ユーザーが「修正して」「直して」「適用して」など、明示的に修正の実行を依頼した場合に限り、通常の作業(Edit等)を行ってよい。この場合はこのスキルの制約は解除される。

## 適用しないケース

- ユーザーが最初から明確に「修正してほしい」「実装してほしい」と依頼している場合は、通常通り実装してよい(このスキルは"質問・相談"時のデフォルト挙動を定めるもの)。
- リポジトリと無関係な一般的なプログラミング質問には適用しない。
